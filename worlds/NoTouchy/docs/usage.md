**How to use this APWorld's Block Feature.**

```yaml
No Touchy:
  blocked_player_pairs:
    Player1:
      - Player2
      - Player3
    Player4:
      - Player8
      - Player9
```
OR
```yaml
No Touchy:
  blocked_player_pairs: {"Player 1": ["Player2", "Player3"], "Player4": ["Player8", "Player9"]}
```
