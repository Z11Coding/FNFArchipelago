# Shortcut Manager

Create custom shortcuts that appear in the Archipelago Launcher. Launch scripts, open folders, visit websites, and more—right from the Launcher.

## Quick Start

1. Open the Launcher and click **Shortcut Manager**
2. Click **Add Shortcut** to create a new shortcut
3. Choose a type, enter a name and target, and save
4. Your shortcut appears in the Launcher immediately

## Shortcut Types

- **Script** - Run Python scripts (e.g., build tools, utilities)
- **Executable** - Run programs (e.g., `.exe` files)
- **Folder** - Open folders in your file explorer
- **URL** - Open websites in your browser
- **Function** - Call Python functions directly


Want a shortcut to appear on an existing Launcher component? Use **Link Shortcut**:

1. Click **Link Shortcut**
2. Choose your shortcut
3. Select the component to link to
4. Choose **Primary** (button next to Open) or **Secondary** (in context menu)

Done! The shortcut now appears with that component.

## Tips

- Use **Browse** buttons to select files/folders instead of typing paths
- Custom icons: Click **Browse...** next to the icon dropdown to use your own image
- Shortcuts are saved automatically
- Delete shortcuts anytime from the manager
